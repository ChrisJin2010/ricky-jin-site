Ricky Jin内容编辑器

登录编辑器

需要一个 GitHub 令牌（token）才能保存改动。生成一次，以后一直用：

  1. 浏览器登录 ChrisJin2010 这个 GitHub 账号
  2. 打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 名字随意（如 editor）；Repository access 选 Only select repositories → ricky-jin-site
  4. Permissions → Repository permissions → Contents 设为 Read and write，其余保持默认
  5. 点 Generate token，复制生成的字符串（github_pat_…）粘贴到下面

令牌只保存在你本机浏览器的 localStorage；保存时通过 GitHub 官方 API 直接提交到你的仓库，不经过任何第三方服务器。不再使用时可在 GitHub 令牌页面随时撤销。

改完点右上角「保存全部改动」，约 1–2 分钟后线上生效（查看时按 Ctrl+F5 强刷） 预览站点 ↗
