编辑网站内容

和在 WorkBuddy 里一样：在页面上直接点文字改、点图片换。

  1. 点下面按钮，进入对应页面的编辑模式（会打开线上页面）
  2. 点文字直接打字修改；点图片位置上传照片（悬停图位有「换图 / 调整 / 移除」按钮——「调整」可以拖动平移、滚轮或滑块缩放，决定照片显示哪一部分）
  3. 改完点页面底部黑色工具条的「保存改动」——第一次会要求你选择电脑上的 ricky-jin-site 文件夹（Documents\Trae-CN\default\ricky-jin-site），之后会自动记住
  4. 打开 GitHub Desktop → Commit to main → Push origin，1–2 分钟后线上生效
