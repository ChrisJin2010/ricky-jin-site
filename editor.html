Ricky Jin内容编辑器

开始使用

  1. 用 Chrome 或 Edge 浏览器打开本页
  2. 点下面的按钮，选择电脑上的 ricky-jin-site 文件夹
    一般在：此电脑 → Documents（文档）→ Trae-CN → default → ricky-jin-site
  3. 改文字、传照片 → 点右上角「保存全部改动」，改动会直接写进这个文件夹
  4. 打开 GitHub Desktop → 点 Commit to main → 点 Push origin，1–2 分钟后线上生效

不需要令牌、不用登录任何账号。编辑器只把文件保存到你电脑上的网站文件夹；上线靠 GitHub Desktop 推送（已登录的账号有推送权限）。下次打开本页会自动记住文件夹，只需点一下授权。

改完点右上角「保存全部改动」写入本地文件夹，再用 GitHub Desktop 推送上线 预览站点 ↗
